### Added

- ND-100 assembler: `nd100-asm <source.uc>`, with the 299 mnemonics of ND-06.018.01
  (`ND1X0/ND100Tokens.cs`, generated by `eng/gen-nd100-tokens.py` from the token YAML of
  nd-microcode-meta). Bits 22-27 are written inverted, as the manual says and as the PROMs hold
  them; branch addresses are 12 bits (bit 20 is the timing bit TC0 on the ND-100).
- ND-100 micro code sources `microcode/ND-100/ND-100-3033S.uc` and `ND-100-3033E-CX.uc`, recovered
  by disassembling the PROM chips (there is no original source). They assemble to the images in
  `microcode/ND-100/REFERENCE/` byte for byte, and split back to all 48 chips with 0 differences.
  `TestND100Compiler` repeats the check.

- Repository created from the `ND110Compile` project of the original ND-110 emulator
  repository: the micro code assemblers and disassemblers for NORD-10, ND-110, ND-120,
  ND-500 and ND-5000, their micro code sources, reference PROM dumps and tests.
