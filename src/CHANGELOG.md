### Added

- ND-100 assembler: `nd100-asm <source.uc>`, with the 300 mnemonics of ND-06.018.01
  (`ND1X0/ND100Tokens.cs`, generated by `eng/gen-nd100-tokens.py` from the token YAML of
  nd-microcode-meta). Bits 22-27 are written inverted, as the manual says and as the PROMs hold
  them; branch addresses are 12 bits (bit 20 is the timing bit TC0 on the ND-100).
- ND-100 micro code sources `microcode/ND-100/ND-100-3033S.uc` and `ND-100-3033E-CX.uc`: the printed
  Norsk Data listing (ND100-MICROCODE.pdf, 1985) written back from the scan, with its labels, comments,
  banners and operand names, and the instruction words of the PROM chips. They assemble to the images in
  `microcode/ND-100/REFERENCE/` byte for byte, and split back to all 48 chips with 0 differences.
  The plain chip decodings are in `microcode/ND-100/DISASSEMBLY/`. `TestND100Compiler` repeats the checks.
- `microcode/ND-100/ND-100-3033S-32BIT-FLOAT.uc`: the 3033S program with the printed 32 bit floating
  point listing (PROM 026XX) in place of the words 0o517-0o1105. No chip dump exists; the words outside
  the replaced part equal the 3033S chips.
- The ND-100 token table has the printed names `XRF` (same bit as `EN_EXT`) and `A,SRCE`; the table's
  earlier `A,SHCE` was a misreading of the dot matrix print of the manual.

- Repository created from the `ND110Compile` project of the original ND-110 emulator
  repository: the micro code assemblers and disassemblers for NORD-10, ND-110, ND-120,
  ND-500 and ND-5000, their micro code sources, reference PROM dumps and tests.
