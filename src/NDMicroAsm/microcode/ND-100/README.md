# ND-100 micro code

| File | What it is |
|---|---|
| `ND-100-3033S.uc` | The micro program of the 3033S CPU card: 2048 words, from the 16 PROM chips. |
| `ND-100-3033E-CX.uc` | The micro program of the 3033E-CX card (the CX option): 2008 words in the base bank and 1529 words in the extension bank at 0o4000 and up, from the 32 chips of both banks. |
| `*.CODE`, `*.LISTING.TXT`, `*.SYMBOLS.TXT`, `*.DETAILS.TXT`, `TOKENS.TXT` | Written by `ndmicroasm nd100-asm`, see below. |
| `REFERENCE/` | The PROM images the sources must reproduce, see `REFERENCE/README.md`. |

## These sources are recovered, not original

There is no Norsk Data source for the ND-100 micro code in any archive known to this project.
The two `.uc` files are the disassembly of the PROM chips, written by
`tools/nd100-prom-to-uc.mjs` of the `nd-microcode-meta` repository, in the mnemonics of
ND-06.018.01 (NORD-100 Microprogramming Description). The labels (`L0027` and so on) are the macro
instruction entry points from the decode PLA chips; they say where the machine instructions start
and carry no original names.

## Assembling

```powershell
ndmicroasm nd100-asm microcode\ND-100\ND-100-3033S.uc
ndmicroasm nd100-asm microcode\ND-100\ND-100-3033E-CX.uc
```

Bits 22-27 of every word are written inverted. ND-06.018.01, chapter 4 (printed page 4-1): "It is
important to be aware that bits 22 - 27 are inverted after the word is assembled." Pages 3-7 and
3-8 call each of the six bits active low. The `.CODE` image is therefore in the form the PROMs
hold, and a reader that wants the active high form flips bits 22-27 again (`XOR 0x0FC00000`, the
same mask as the ND-110). Branch addresses are 12 bits; bit 20 is the timing bit TC0 and the
assembler does not touch it for a label.

## Proof against the chips

Checked on 19 October 2026:

- `ND-100-3033S.CODE` is byte for byte equal to `REFERENCE/3033S-microcode.CODE` (20480 bytes).
- `ND-100-3033E-CX.CODE` is equal to the two reference files of the CX card put together
  (35370 bytes).
- Split back into chips with the layout of `tools/nd100-combine.py`, all 48 chips (16 of the 3033S,
  16 + 16 of the 3033E-CX base and extension) have 0 differing nibbles over 32768 nibbles each bank.
- `TestND100Compiler` in `src/tests/NDMicroAsm.Tests` repeats the first two checks.

The mnemonic table (`ND1X0/ND100Tokens.cs`) is generated by `eng/gen-nd100-tokens.py` from
`defs/tokens/nd100-tokens.yaml` of `nd-microcode-meta`. Every token the 3033S and 3033E-CX chips use
is proved by the match above; a token that no chip word uses has not been checked against the
printed mnemonic list (Appendix A of ND-06.018.01), because the OCR text of that list is not
usable and it has to be read from the scan.
