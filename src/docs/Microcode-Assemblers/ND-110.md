# ND-110 assembler

The ND-110 and ND-120 share one assembler, `ND1X0/Compiler.cs`. The ND-110 table is `ND1X0/ND110Tokens.cs`.
The ND-100 uses the same source dialect, see [ND-100](ND-100.md); the ND-120 differences are on the
[ND-120](ND-120.md) page.

- **Micro word**: 64 bits.
- **Token values**: the ND-110/ND-120 Microprogrammer's Guide, ND-06.031.1 EN. `NDMicroAsm/microcode/ND-110/TOKENS.TXT`
  is a dump of the table the assembler used.
- **Source dialect** (read from `Compiler.cs`):
  - `%` starts a comment that runs to the end of the line
  - `nnnn/` sets the micro address; the number is octal unless it starts with `0x`, `$` or `o`
  - `NAME:` (a colon within the first 30 characters of the line) defines a label at the current address
  - an instruction is every text up to the line that holds `;`; it may span several lines, and the
    printed layout puts the A/B and ALU fields on the first line, the IDBS/COMM/T fields on the second,
    and the jump address on the third
  - a mnemonic is a token such as `IDBS,ARG` or `COMM,EWRF`; spaces after a comma are ignored
  - a label operand sets the branch address in bits 11-0 and bit 12 of the address in bit 20
  - a number in an instruction with `T,JMP`, `T,JMP0-3` or `T,JMPAOPR` and no `COND,` token is a branch
    address of up to 13 bits, split the same way as a label; any other number is OR-ed into bits 15-0
- **Output**: `.CODE` is a list of 10-byte records, each the address (2 bytes) and the word (8 bytes), both
  little-endian. It holds only the words the source defines, not a full control store. The image is in the form of the
  EPROMs of the 3095 card: 4257 of the 4865 RASK words equal the chip word (see below), so nothing is
  inverted afterwards.
- **Other files** next to the source: `.LISTING.TXT`, `.SYMBOLS.TXT`, `.DETAILS.TXT`, see
  [the overview](../Microcode-Assemblers.md#files-the-assemblers-write).
- **Source in `NDMicroAsm/microcode/ND-110/`**: `ND-110-RASK.uc`, the RASK micro program, micro code version 0o13.
  The EPROM images of the 3095 card (version 0o14) are in `NDMicroAsm/microcode/ND-110/REFERENCE/`, with a
  [README](../../NDMicroAsm/microcode/ND-110/README.md) on the chip layout. 4257 words of the source equal the
  chips; the 608 others are the changes between the two versions (the version word and 368 words that differ
  in bit 27 only).
- **Tests**: `ND110_Rask_AgainstTheEprom` in `tests/NDMicroAsm.Tests/TestND1X0Compiler.cs` checks those numbers.
- **Command line**: `ndmicroasm nd110-asm <source.uc>`. There is no ND-110 disassembler in this tool; the
  [VS Code extension](https://retrocorelabs.github.io/vscode-nd-microcode/) and the
  [nd100uc web page](https://retrocorelabs.github.io/nd100uc/) have one.
