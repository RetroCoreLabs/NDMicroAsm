# ND-100 assembler

The ND-100 is assembled by the same class as the ND-110 and ND-120 (`ND1X0/Compiler.cs`, method
`AssembleFileND100`), with its own token table `ND1X0/ND100Tokens.cs`.

- **Micro word**: 64 bits in the image, 48 used. A record of the `.CODE` file is 10 bytes: the address
  (2 bytes, little-endian) and the word (8 bytes, little-endian).
- **Token values**: 300 mnemonics of ND-06.018.01 "NORD-100 Microprogramming Description".
  `ND100Tokens.cs` is generated by `src/eng/gen-nd100-tokens.py` from `defs/tokens/nd100-tokens.yaml` of
  the nd-microcode-meta repository. Do not edit the C# file by hand.
- **Bits 22-27 are written inverted**, as ND-06.018.01 chapter 4 (printed page 4-1) says and as the PROMs
  hold them. The `.CODE` image is therefore in PROM form. The comment of `AssembleFileND100` says the ND-110 assembler does the same (not checked here).
- **Branch address**: 12 bits (bits 11-0). Bit 20 is the timing bit TC0 and the assembler does not touch it
  for a label. A label above 0o7777 gives a console message that names the label and the address.
- **Source dialect**: the ND-110 and ND-120 dialect, see [ND-110](ND-110.md). The ND-100 sources keep the
  look of the printed Norsk Data listing: `A,17`, `B,0`, `T,POP 1560;`, the one-line vector tables.
- **Sources in `NDMicroAsm/microcode/ND-100/`**: `ND-100-3033S.uc` (the 3033S card, 2048 words),
  `ND-100-3033E-CX.uc` (the 3033E-CX card: the base bank and the CX option bank from 0o4000) and
  `ND-100-3033S-32BIT-FLOAT.uc` (the 3033S program with the printed 32 bit floating point routines;
  no chip dump exists for it).
- **Proof**: the 3033S and 3033E-CX sources assemble byte for byte to the PROM images in
  `NDMicroAsm/microcode/ND-100/REFERENCE/` (20480 and 35370 bytes). `TestND100Compiler` repeats the checks.
- **More**: how the sources were made from the printed listing, what the chips hold that the print does not
  say (the `CYCL` bits, 0o3514-0o3517), and the `_CX` names are in the
  [ND-100 micro code README](../../NDMicroAsm/microcode/ND-100/README.md). The mapping PROM that turns a
  machine instruction into a first micro address is in
  [the ND-100 mapping PROM page](../../NDMicroAsm/microcode/ND-100/ND-100-MAPPING.md).
- **Command line**: `ndmicroasm nd100-asm <source.uc>`. There is no ND-100 disassembler in this tool.
