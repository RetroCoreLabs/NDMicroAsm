# ND-120 assembler

The ND-120 uses the ND-110 assembler (`ND1X0/Compiler.cs`) with its own token table,
`ND1X0/ND120Tokens.cs`. The source dialect and the `.CODE` record format are described on the
[ND-110](ND-110.md) page.

- **Micro word**: 64 bits.
- **Versions K and L**: `ndmicroasm nd120-asm <source.uc> [K|L]`, default K. Version K is the token table as
  loaded. Version L applies `ND120Tokens.AdjustTokensForVersionL` after loading: the register-select tokens
  `B,P`, `B,B` and `B,X` lose the `DLY1` delay bit (word 2, `004000`). The register numbers stay 2, 3 and 7.
  `NDMicroAsm/microcode/ND-120/TOKENS.TXT` and `TOKENS-L.TXT` are the two dumps.
- **Sources in `NDMicroAsm/microcode/ND-120/`**:
  - `ND-120-DELILAH-K.uc`, version K, written from the printed listing
  - `ND-120-DELILAH-L.uc`, version L; all 4886 of its words equal the words of the ND-120 EPROM pair in
    `NDMicroAsm/microcode/ND-120/REFERENCE/` (a test checks this)
  - `ND-120-DELILAH-L-PATCH.uc`, version L with `COMM,LDIRV` in word 2 of IOXG (so says the comment in `src/eng/assemble-all.ps1`; the source itself has no note about it)
- **Use the right version**: assembling a K source as L, or an L source as K, changes 235 bytes of the image
  (measured on 21 October 2026 with the TypeScript assembler of the VS Code extension, which gives the same
  output as this tool for these sources).
- **Image form**: not inverted; the DELILAH-L image equals the chips as assembled.
- **Tests**: `ND120_DelilahL_EqualsTheEpromWordForWord`, `ND120_DelilahLPatch_DiffersFromTheEpromInOneWord` and
  `ND120_VersionL_RemovesDly1FromTheRegisterSelectTokens` in `tests/NDMicroAsm.Tests/TestND1X0Compiler.cs`.
  The folder [README](../../NDMicroAsm/microcode/ND-120/README.md) has the numbers.
- **Command line**: `ndmicroasm nd120-asm <source.uc> [K|L]`. There is no ND-120 disassembler in this tool.
